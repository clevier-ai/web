# Logo definitivo Clevier

**Marca:** monograma CL manuscrito a **67°** (lee “CL” de Clevier).
Es el que usa la web (`Header`, `Footer`, favicon) y `public/brand/cl-mark.svg`.


## Principales (raíz)

| Archivo | Uso |
|---|---|
| `clevier-logo-fondo.png` | GitHub, LinkedIn y perfiles (negro sobre blanco, margen seguro) |
| `clevier-logo.png` | Mismo mark, fondo transparente |

Ambos son 1024×1024, mark ~56% del lienzo para que el recorte circular no corte bordes.

## Origen

`original/cl.jpg` — el trazo original que empezó la marca (también en `brand/cl.jpg`).
El mark a 67° es esa misma forma, orientada para leerse como CL.

## Uso

| Variante | Color | Cuándo |
|---|---|---|
| `cl-mark-grafit` | `#1F2328` | Primaria sobre papel / claro |
| `cl-mark-tinta` | `#1A1C1E` | Alineada a tokens CSS actuales |
| `cl-mark-verd` | `#2FBF71` | Acento / favicon sobre grafito |
| `cl-mark-llima` | `#C8F169` | CTA / fondos oscuros |
| `cl-mark-blanc` | `#FFFFFF` | Sobre nit / grafito |
| `cl-mark-negro` | `#000000` | LinkedIn, GitHub y plataformas (PNG) |

`cl-mark.svg` = alias de grafit (versión canónica).

Para perfiles (LinkedIn, GitHub, etc.): usa **`png/cl-mark-negro.png`** (1024, transparente).

## Carpetas

- `original/` — foto/trazo de partida
- `svg/` — vectorial (fuente de verdad)
- `png/` — raster 512 y 1024 (transparente)
- `favicon/` — icono adaptable + app icon verd sobre grafito

## Notas

- Un solo path; no hay twotone en el mark definitivo.
- No recolorar fuera de esta paleta.
- Lockup web: mark + tipografía “evier” (gap `-0.09em`).
